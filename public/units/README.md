# Unit portraits

Drop a square PNG named `<id>.png` here (e.g. `0.png`, `1.png`, …) and the
gacha will use it as that character's portrait. Missing files fall back to a
generated monogram crest, so the roster works with or without art.

`<id>` is the unit's index in the catalogue (`src/lib/gacha.ts`, in `CATALOGUE`
order: Legendary first, then UR, SSR, SR, R). Recommended size: 256×256.
